# 0.5.3.0: Strata and FreeToken providers, VPN-aware discovery, retry and UI fixes

Minor release since **v0.5.2.0** (2026-08-23). Adds two local providers and overlay-network peer discovery, and fixes how upstream retries interact with failover, how the dashboard authenticates from another machine, and how the macOS source editor handles structured fields. Includes everything in **0.5.2.0**.

## New

- **Strata local provider (PR #88)**: discovery for Strata on Linux and Windows, with optional engine auto-load (`strata_auto_load`) before a request is routed to an unloaded engine. See [docs/strata-integration.md](../strata-integration.md).
- **FreeToken local provider (PR #79)**: discovery for the FreeToken provider on Linux.
- **VPN-aware overlay peer discovery (PR #77)**: peers reachable over a VPN or overlay network are found through mesh gossip, and requests fail over between a peer's candidate paths. See [docs/overlay-peer-discovery.md](../overlay-peer-discovery.md).
- **Dashboard cluster-token sign-in (PR #150)**: a browser that is not on the agent's own machine now gets a read-only notice with a token field instead of "Could not reach the agent". The token is sent as a Bearer header and kept for the tab only.

## Fixed

- **Vendor SDK retries no longer hide failures from failover (PR #148)**: the OpenAI and Anthropic SDK clients defaulted to two in-place retries, so an embeddings or Anthropic-format call to a slow or busy node was replayed on that node up to three times before the router could fail over. Both adapters now disable SDK retries; the router owns retries.
- **macOS source editor no longer overwrites structured fields (PR #150)**: `model_rewrites`, `scenarios` and `match` on a source were replaced by a string on the first keystroke. The macOS form now has real controls for dict, list and object fields.
- **Local-trust hardening (PR #149)**: requests from this machine's own addresses are now trusted only when they are not browser-originated from another site. Non-browser local callers (CLI, menubar app, harnesses) and token-authenticated callers are unaffected.
- **Windows telemetry test (PR #150)**: the TTFT stream test no longer fails on Windows' 15.6 ms clock tick.

## Behaviour changes

- Opening the dashboard on the same machine through a DNS name other than `localhost`, the hostname, or `<hostname>.local` (for example a VPN MagicDNS name) now returns 403 on admin routes. Use the IP address or `localhost`.
- A cloud provider that is the only candidate for a model no longer gets the SDK's in-place retries on a transient 429 or 5xx.

## Upgrade

Upgrade the **gateway first**, then peers ([docs/mesh-upgrade.md](../mesh-upgrade.md)).

### macOS

From a git checkout (macOS 26+):

```bash
git checkout v0.5.3.0
uv sync
apps/netllm-mac/Scripts/build.sh release
packaging/scripts/macos-app-install.sh --source apps/netllm-mac/build/Stage/llm-swarm-router.app
```

The DMG is attached once it has been built and notarized; until then use the source build above. The macOS Swift changes in this release were not compiled by the maintainer's Linux host; CI `menubar-lifecycle` builds them.

### CLI / Linux / Windows

```bash
git checkout v0.5.3.0
uv sync
./netllm drain on    # optional: let in-flight work finish
./netllm restart     # or systemctl --user restart netllm / menubar Restart Agent
```

Hard-refresh the dashboard (`Cmd+Shift+R`) if cached `dashboard.js` is stale.

Verify:

```bash
curl -sf http://127.0.0.1:11400/health
./netllm doctor
./netllm test
```
